- **A live replay (`flair rem restore --apply` without `--dry-run`) lists leftover candidates on its write target.** The admin-only `GET /AdminMemoryCandidates/{agentId}` route returns one agent's candidate ids, bounded by `limit`, and fails the request (`candidate_id_unusable`) rather than leave out a row it reads without a usable id. A live replay that gets no complete listing (`hasMore: true`, a malformed reply or a failed request) is refused before any target-row delete or write; one whose candidate request the target answers with HTTP 404 is refused, naming Flair 0.63.0 as the version that adds the route.
