- **The CLI spawn-budget gate masks JSX text before matching spawn calls and reading deadlines.** Text inside JSX elements is replaced with spaces of the same length, with line breaks kept, so an apostrophe, a quote or `//` in that text no longer opens a string or comment in the gate's bracket walks and drops the call or case around it. A JSX attribute's string value is a TypeScript string literal, which the literal masker already handles.
